## 🚀 NÄSTA STEG FÖR VERCEL

### 1. Koppla GitHub till Vercel

1. Gå till **Vercel Dashboard** (https://vercel.com)
2. Klicka **"Add New Project"**
3. Välj **"Import Git Repository"**
4. Välj **paradoxapiko-maker/aurelia-market**
5. Klicka **"Import"**

### 2. Konfigurera Environment Variables

Lägg till dessa i Vercel:

```
TURSO_DATABASE_URL=libsql://dostar-dostar.aws-ap-northeast-1.turso.io
TURSO_AUTH_TOKEN=[din-turso-token]
JWT_SECRET=[din-jwt-secret]
NEXT_PUBLIC_STRIPE_PUBLIC_KEY=[din-stripe-public-key]
STRIPE_SECRET_KEY=[din-stripe-secret-key]
NEXT_PUBLIC_APP_URL=https://din-url.vercel.app
```

**VIKTIGT:** Kopiera värdena från `.env.local`

### 3. Deploy

1. Klicka **"Deploy"**
2. Vänta ~3-6 minuter
3. Deployment klar!
